# procesos/ — Cómo hacemos las cosas en JorZunex

Un archivo Markdown por proceso (`<nombre-proceso>.md`). Esto es lo que le permite al
Brain actuar como alguien del equipo que ya sabe "cómo se hace aquí" — pilar 1 de
`docs/VISION.md` — y más adelante ejecutar partes del proceso (pilar 3, motor comercial).

Procesos candidatos (créalos según los necesites, no hace falta todos de golpe):
- `captacion-clientes.md` — cómo llega un lead, cómo se cualifica, cómo se convierte en propuesta.
- `facturacion.md` — ver ejemplo esqueleto en esta carpeta.
- `entrega-proyecto.md` — checklist de cómo se cierra y entrega un proyecto al cliente.
- `onboarding-equipo.md` — qué necesita alguien nuevo el primer día/semana.

Plantilla base para cualquier proceso nuevo:

```markdown
---
tipo: proceso
actualizado: YYYY-MM-DD
---

# <Nombre del proceso>

## Cuándo se usa
## Pasos
1.
2.
## Quién lo hace / responsable
## Herramientas involucradas
## Errores comunes a evitar
```

5 minutos por archivo: apunta lo esencial, no escribas un manual. Se puede ampliar después.

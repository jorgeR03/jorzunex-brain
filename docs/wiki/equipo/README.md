# equipo/ — Perfiles del equipo

Un archivo Markdown por persona (`<nombre>.md`), con este formato mínimo:

```markdown
---
tipo: perfil-persona
actualizado: YYYY-MM-DD
---

# <Nombre>

## Rol
## Proyectos actuales
## Preferencias de trabajo / comunicación
## Contexto relevante para el Brain
```

Esto es lo que el pilar 1 de `docs/VISION.md` ("sabe todo de mí y de mi equipo") necesita para funcionar. Empieza creando `jorge.md`.

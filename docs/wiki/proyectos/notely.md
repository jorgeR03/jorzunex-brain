# Notion_2.0 (Notely)

## Objetivo
Según su propio README, es una aplicación full-stack de notas con etiquetas y
filtrado ("Notely — Notes App"). No hay ninguna otra fuente (Drive, web, CV,
presentaciones) que mencione este proyecto como un producto real de JorZunex
Solutions.

## Estado actual
**Incierto** — todo apunta a que es un proyecto de práctica/aprendizaje (stack
genérico: React+Vite+NestJS+Prisma+SQLite, sin multi-tenancy, sin pagos, sin
marca JorZunex en el README) más que un producto comercial como el resto de la
carpeta `ProyectosJorZunex`. Se documenta aquí por transparencia (estaba en la
lista de 10 proyectos a revisar) pero **recomendado confirmar con Jorge** si:
(a) es solo un ejercicio de aprendizaje sin relación con el negocio, o
(b) es la semilla de un producto de gestión de conocimiento/notas que sí se
planea desarrollar.

## Decisiones clave
- Stack: React 18 + Vite + TypeScript + Tailwind (frontend), NestJS 10 + Prisma +
  SQLite (backend) — el uso de SQLite (en vez de PostgreSQL como el resto de
  productos JorZunex) refuerza la hipótesis de proyecto de práctica.
